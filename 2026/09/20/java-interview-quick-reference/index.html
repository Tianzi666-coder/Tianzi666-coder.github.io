Java 基础

问题 一句话答案
== 和 equals == 比地址（基本类型比值），equals 默认比地址、String 等重写为比内容
String 为什么不可变 final 数组 + 不提供修改方法；带来线程安全、可做常量池 key
接口和抽象类 接口可多实现、只能有常量；抽象类可单继承、可有状态
重载和重写 编译期看引用类型（重载），运行期看实际对象（重写）

集合

问题 一句话答案
ArrayList vs LinkedList 数组 vs 双向链表；随机访问 ArrayList 快，头尾增删 LinkedList 快
HashMap 容量为什么 2 的幂 (n-1) & hash 等价取模且更快，扩容时元素要么原位要么移 oldCap
HashMap 线程安全吗 不安全；并发用 ConcurrentHashMap

并发

问题 一句话答案
volatile 作用 可见性 + 禁止重排序，不保证原子性
synchronized 锁升级 无锁 → 偏向锁 → 轻量级锁（自旋）→ 重量级锁
线程池执行顺序 核心线程 → 队列 → 扩容到 max → 拒绝策略
ThreadLocal 内存泄漏 key 是弱引用、value 是强引用；用完要 remove()

MySQL

问题 一句话答案
事务四大特性 原子性（undo）、一致性、隔离性（锁/MVCC）、持久性（redo）
隔离级别 读未提交 / 读已提交 / 可重复读（默认） / 串行化
幻读怎么解决 RR 下用间隙锁（Next-Key Lock）
索引失效 函数运算、隐式转换、前导 %、不满足最左前缀

Redis

问题 一句话答案
为什么快 纯内存 + IO 多路复用 + 单线程无锁竞争
持久化 RDB（快照，恢复快丢数据多）/ AOF（日志，丢数据少）
缓存穿透 缓存空值 / 布隆过滤器
分布式锁 SET key value NX PX 30000 + Lua 校验 value 删除

微服务

问题 一句话答案
服务怎么发现彼此 注册中心（Nacos）按服务名解析实例
网关做什么 路由、鉴权、限流、日志，统一入口
分布式事务方案 2PC / TCC / 本地消息表 / Seata AT

面试技巧

  • 答”是什么”之后主动补一句”为什么”（比如”用 CAS 是为了避免加锁开销”）；
  • 被问住就说”这个我不太确定，我的理解是…”，别硬编；
  • 每个技术点准备一个自己项目里的例子，比背概念有说服力。
