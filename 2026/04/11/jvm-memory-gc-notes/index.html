运行时数据区

区域 线程 说明
程序计数器 私有 当前字节码行号，唯一不会 OOM 的区域
虚拟机栈 私有 每个方法一个栈帧（局部变量表、操作数栈）
本地方法栈 私有 native 方法
堆 共享 对象实例，GC 主战场
方法区（元空间） 共享 类元信息、常量、静态变量，JDK 8 后移出堆

对象怎么判死

可达性分析：从 GC Roots 出发，不可达即可回收。

GC Roots 包括：虚拟机栈中的引用、方法区静态属性、常量引用、JNI 引用、活跃线程。

为什么不只用引用计数？解决不了循环引用。

分代与回收算法

  • 新生代（Eden : S0 : S1 = 8 : 1 : 1）：对象优先在 Eden 分配，复制算法，存活对象少、复制成本低；
  • 老年代：大对象、长期存活对象，标记-清除 / 标记-整理。

对象晋升老年代的条件：

  1. 年龄达到阈值（默认 15，-XX:MaxTenuringThreshold）；
  2. 大对象直接进老年代（-XX:PretenureSizeThreshold）；
  3. 动态年龄判断：Survivor 中同龄对象总和 > 一半，年龄 ≥ 该年龄的直接晋升。

收集器 特点
Serial / Serial Old 单线程，客户端模式
ParNew / Parallel Scavenge 多线程，关注吞吐量
CMS 并发标记清除，低停顿，有碎片
G1 分 Region，可预测停顿，JDK 9+ 默认
ZGC 超低停顿（< 10ms），大堆场景
